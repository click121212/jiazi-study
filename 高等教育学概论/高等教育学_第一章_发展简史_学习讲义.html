第一节

中国高等教育发展史

讲义核心考点：古代中国——从萌芽到雏形
  1. 殷商"右学"：我国最早具有高等教育某些属性的机构
  2. 西周：天子大学称"辟雍"，诸侯大学称"泮宫"；特点：学在官府、官学不分、政教不分，教育对象为天子贵族子弟；教"六艺"＝礼、乐、射、御、书、数
  3. 春秋战国：私学兴起（孔子、老子、孟子、庄子、墨子、荀子及齐国稷下学宫）；《大学》《学记》是世界上最早的教育著作；意义：打破学在官府、有教无类
  4. 秦朝："焚书坑儒"、禁止私学，高等教育短暂倒退
  5. 公元前124年：汉武帝采纳董仲舒建议设立太学——标志古代高等教育由萌芽进入雏形阶段；教材"五经"（诗书礼易春秋）；考核：口试、策试、射试；教师称"博士"，校长西汉称"仆射"、东汉称"祭酒"；读书自此成为进入仕途的"敲门砖"
  6. 鸿都门学（东汉）：世界上第一所文学、艺术专科学校
讲义核心考点：唐代"六学"与书院

唐代是封建社会教育最发达时期。中央官学"六学"：国子学、太学、四门学、律学、书学、算学（归国子监）——口诀"国太四律书算"。

确立专业教育、设置专门实科学校是唐代对古代高等教育的最大贡献。

书院：名始于唐但非教育机构，宋初才成为高等教育机构（既是教学机构也是学术机构）；明末以东林书院为代表；1901年清光绪下令改书院为学堂。

书院六大特点：机构精干（山长/洞主总理其事）、教学与研究结合、允许不同学派讲学论辩、一师可到多书院讲学、重视自学与独立研究、师生关系融洽。

讲义核心考点：近代中国——三个"第一所"
机构年份地位
京师同文馆1862我国第一所新式学堂
天津西学学堂1895第一所分科大学（分头等/二等学堂两级）
京师大学堂1898第一所国立大学（7科13门）

口诀："同文新式、西学分科、京堂国立"。后二者创办标志我国近代高等教育正式开端。

讲义核心考点：学制确立与民国法令
  1. 1902年《壬寅学制》：未实施；1904年《癸卯学制》：实施，制度正式确立。癸卯学制高等教育分三级：高等学堂或大学预科（3年）、大学堂（3—4年）、通儒院（5年，相当于研究生阶段），另设实业学堂和师范学堂
  2. 民国：1912年《大学令》、1917年《私立大学规章》《修正大学令》，废除"忠君"，提出"以教授高深学问，养成硕学宏才应国家需要"的宗旨
讲义核心考点：现代中国——蔡元培与当代体系
  1. 蔡元培1916年12月任北大校长：大学是研究学术、培养人才的场所，不是升官发财的阶梯；思想自由、兼容并包；改革体制、民主管理；首倡选科制、改学年制为学分制——开启我国近代大学向现代大学的转变
  2. 1948年底全国高校218所；师范教育独立建制由抗战前1所增至38所（占12.84%）
  3. 1921年毛泽东创办湖南自修大学；1922年中共创办上海大学
  4. 1952—1953年学苏联进行院系调整：本科分综合大学、多科性理工学院、单科性专门学院三类
  5. 1961年9月"高校六十条"（《教育部直属高校暂行工作条例（草案）》）标志社会主义高等教育体系初步形成
  6. 1998年8月《高等教育法》将"党委领导下的校长负责制"以法律形式固定
  7. "211工程"1995年实施（重点建设100所左右高校和一批重点学科，内容含学校整体条件、重点学科、公共服务体系三部分）；"985工程"源于1998年5月4日江泽民在北大百年校庆大会宣告（内容含机制创新、队伍建设、平台基地建设、条件支撑、国际交流合作五部分）
  8. 1999年起高校扩大招生；2003—2008年教育部开展第一轮本科教学工作水平评估
  9. 改革：办学体制"一主多元"；调整隶属关系八字方针"共建、调整、合作、合并"；经费以国家财政拨款为主多渠道筹措；1978年武汉大学、南京大学率先试行学分制

第一节 小结

  • 萌芽＝殷商右学；雏形＝汉代太学（前124年董仲舒）；近代开端＝1895西学学堂+1898京师大学堂
  • 唐代"六学"＝专业教育最大贡献；书院宋初成高教机构
  • 三个"第一所"：同文馆（新式学堂）、西学学堂（分科大学）、京师大学堂（国立大学）
  • 壬寅未实施、癸卯实施；蔡元培开现代大学之先；高校六十条标志体系形成；211（1995）/985（1998）
第二节

外国高等教育发展史

定义：

中世纪大学：西欧中世纪后期（12—13世纪）由学者行会发展而成的自治教育机构，设文、法、医、神四科，以讲课和辩论为教学方式，是欧美近代大学的渊源。

毛入学率：高等学校在学学生数占适龄人口的比例，是衡量高等教育发展水平的重要指标。

讲义核心考点：古代外国——雅典大学与中世纪大学
  1. 雅典大学：公元前200年左右哲学学校与修辞学校合并成立，欧美教育史家称之为世界高等教育史上第一所大学；9世纪初巴格达赫克迈大学是阿拉伯地区第一所大学
  2. 中世纪大学：意大利波隆亚（1158）、萨莱诺（1231）；英国牛津（1168）、剑桥（1209）；法国巴黎（1180）；捷克布拉格（1348）；德国维也纳（1365）。设文、法、医、神四科，文科为预科性质，课程为"七艺"（文法、修辞、辩证法、算术、几何、天文、音乐）；教学以讲课和辩论为主
  3. 意义：打破教会对大学的垄断、获得较大自治权，成为欧美近代大学的渊源
讲义核心考点：近代外国——英法德美四大模式
国家事件意义/特点
英国1826年伦敦新学院；1851年曼彻斯特欧文斯学院（"新大学"运动）打破宗教信仰限制、重视技术教育设工程技术专业、多为地方捐资兴办
法国巴黎工业专科学校；巴黎高等师范学校；1806年帝国大学（法兰西大学）帝国大学实为全国教育行政领导机构；巴黎工业专科学校被誉为"欧洲工业大学最早的模范"
德国1810年洪堡创办柏林大学首次提出"教学与科研相统一"；公认第一所具有现代意义的大学
美国1636年哈佛学院；1862年林肯签署《赠地法案》（莫里尔法案）；1876年约翰·霍普金斯大学哈佛＝美国第一所高校；赠地学院确立教育为经济及社会服务原则；霍普金斯＝美国现代大学之始（德国式研究生院）
讲义核心考点：洪堡柏林大学的五条措施
  1. 大学自治
  2. 学术自由、科研至上
  3. 破除灌输式教授制度，让学生在研究中学习
  4. 教授治校
  5. 严格聘任制
讲义核心考点：外国现代与"威斯康星思想"
  1. 日本第一所大学：1877年东京大学（1880年建研究生院）；俄国：1632年基辅学院，1755年莫斯科大学（仅设哲学、医学、法律三系）
  2. 1958年美国《国防教育法》（受1957年苏联人造卫星刺激），把教育列为国家优先发展战略
  3. 20世纪60年代日本明确"教育立国"
  4. 威斯康星思想：威斯康星大学校长范·海斯提出"服务应当成为大学的唯一理想"
  5. 教学、科研、社会服务三位一体是现代大学功能的高度概括
理解要点（"世界高校第一"链条）

雅典大学＝世界高教史上第一所大学（公元前200年）；柏林大学＝第一所具有现代意义的大学（1810，洪堡）；哈佛＝美国第一所高校（1636）；霍普金斯＝美国现代大学之始（1876）。四个"第一"不要记混。

第二节 小结

  • 中世纪大学四科：文法医神；课程"七艺"
  • 柏林大学＝教学与科研相统一，第一所现代意义大学
  • 美国：《赠地法案》（1862）服务社会 + 霍普金斯研究生院（1876）
  • 1958《国防教育法》；威斯康星思想＝服务社会
第三节

当代高等教育的发展特点和趋势

讲义核心考点：大众化与普及化（马丁·特罗理论）

马丁·特罗（美国社会学家，20世纪70年代）三阶段论：

毛入学率阶段
15%以下精英教育阶段
15%—50%大众教育阶段
50%以上普及教育阶段

口诀"一五零、分三档"。美国20世纪40年代率先进入大众化，1989年毛入学率51.4%进入普及化。

讲义核心考点：我国高等教育大众化进程
  1. 1998年12月《面向21世纪教育振兴行动计划》提出到2010年入学率接近15%
  2. 1999年开始扩招；2002年毛入学率达15%，按国际标准迈入大众化阶段（当年上海51%、北京49%）
  3. 2008年总规模2907万人、毛入学率23.3%
  4. 高等教育多样化是实现大众化的必由之路；我国多样化表现：办学主体（"一主多元"）、办学形式、教育目标、教学内容、培养方式五个方面
讲义核心考点：经济全球化与高等教育国际化

我国高等教育国际化五大表现：

  1. 留学生人数不断增加
  2. 来华留学生不断增加
  3. 合作办学不断增多
  4. 课程不断国际化（MBA、国际金融、国际贸易、国际法等）
  5. 建立海外孔子学院，扩大中国文化影响
讲义核心考点：学习化社会与终身教育
  1. 1965年保罗·朗格朗（法国人）在成人教育促进国际会议首次正式提出"终身教育"
  2. 1968年哈钦斯首次提出"学习化社会"
  3. 1972年联合国教科文组织《学会生存——教育世界的今天和明天》首次并列提出"终身教育、终身学习、学习化社会"三个基本概念
  4. 1993年《中国教育改革和发展纲要》第一次正式提出"终身教育"
理解要点

终身教育＝从生到死不间断的终身过程（朗格朗1965）；学习化社会＝人在任何人生发展阶段都能学习的社会（哈钦斯1968）。《学会生存》（1972）把三者并列——人物、年份、文献要一一对应。

高频考点/易混淆点

三阶段判断速记：毛入学率不足15%＝精英；15%—50%＝大众；超过50%＝普及。我国2002年（15%）、美国1989年（51.4%）分别对应"进入大众化""进入普及化"，年份与数值要能一一对应。

易混：终身教育（朗格朗1965）vs 终身学习（学习者视角）vs 学习化社会（哈钦斯1968）——三者首次并列出现在1972年《学会生存》。

第三节 小结

  • 特罗三阶段：15%精英 / 15—50%大众 / 50%以上普及
  • 我国2002年迈入大众化；多样化是大众化必由之路
  • 国际化五表现：派出、来华、合作办学、课程国际化、孔子学院
  • 终身教育朗格朗1965 / 学习化社会哈钦斯1968 / 《学会生存》1972

第一章备考要点速览

一、必背定义与概念

  • 六艺：西周教育内容＝礼、乐、射、御、书、数
  • 毛入学率：高等学校学生占适龄人口的比例
  • 马丁·特罗三阶段：15%以下精英、15%—50%大众、50%以上普及
  • 终身教育：教育是从生到死不间断的终身过程（朗格朗1965）
  • 学习化社会：人在任何人生发展阶段都能学习的社会（哈钦斯1968）

二、高频考点清单

  • ★ 殷商右学＝萌芽；汉代太学（前124，董仲舒）＝雏形
  • ★ 唐代"六学"＝专业教育最大贡献（国太四律书算）
  • ★ 三个"第一所"：同文馆1862新式学堂 / 西学学堂1895分科大学 / 京师大学堂1898国立大学
  • ★ 壬寅学制1902未实施、癸卯学制1904实施
  • ★ 蔡元培北大改革：思想自由兼容并包、选科制、学分制
  • ★ 高校六十条1961体系初步形成；211（1995）/985（1998）
  • ★ 雅典大学＝世界第一所；柏林大学1810＝第一所现代意义大学；霍普金斯1876＝美国现代大学之始
  • ★ 洪堡"教学与科研相统一"；威斯康星思想＝服务社会

三、易混知识点辨析

  • 壬寅 vs 癸卯学制：壬寅1902未实施 vs 癸卯1904实施（制度正式确立）
  • "六艺" vs "六学" vs "七艺"：西周六艺（礼乐射御书数）vs 唐代六学（国太四律书算）vs 中世纪七艺（文法修辞辩证法算术几何天文音乐）
  • 四个"第一"：雅典（世界第一所大学）/柏林（第一所现代意义大学）/哈佛（美国第一所高校）/霍普金斯（美国现代大学之始）
  • 终身教育 vs 学习化社会：朗格朗1965 vs 哈钦斯1968；首次并列＝1972《学会生存》
