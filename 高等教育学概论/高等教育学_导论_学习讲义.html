第一节

高等教育学与教育学的主要区别

讲义核心考点：高等教育的定义

高等教育：对中等教育以上程度的人，以传授和研究各种科学、技术、艺术等有关学问为主要活动，承担培养高级专门人才、发展科学技术文化、促进现代化建设的重大任务。高等教育是有一定专业方向的教育。

三种权威定义：

  1. 联合国教科文组织：由大学、文理学院、理工学院、师范学院等机构实施的各种类型的教育
  2. 我国《高等教育法》："本法所称的高等教育，是指在完成高级中学教育基础上实施的教育"
  3. 高等教育 vs 高等教育学：高等教育是一种教育活动，高等教育学是研究高等教育活动规律的科学

一、教育学的内涵与研究对象的经典表述

理解要点

《说文解字》："教，上所施，下所教也"；"育，养子使作善也"（汉代，两千年前）。

裴斯泰洛齐（瑞士）：教育就是"依照自然的法则，发展儿童道德、智慧和身体各方面的能力"。

杜威（美国实用主义）："教育即生活，教育即生长"。

毛泽东："科学研究的区分，就是根据科学对象构成某一学科的对象"——论证教育学有独立研究对象。

一句话串记：《说文解字》奠基 → 裴斯泰洛齐自然法则 → 杜威生活教育 → 毛泽东对象论。

讲义核心考点：高等教育学的研究对象与学科地位

研究对象：以高等教育的特殊矛盾与基本规律为研究对象，即以怎样培养高级专门人才为研究对象，探索和揭示高等教育活动规律的科学。

  1. 高等教育学是教育学的分支，又是相对独立的二级学科，属于社会科学
  2. 独立学科标志：20世纪50年代末潘懋元教授《高等教育学讲座》问世（我国高等教育研究活动开始的标志）
  3. 发展分期：70年代末—80年代中期＝初创阶段；80年代中期—90年代末＝发展阶段

二、高等教育与普通教育（基础教育）的五点区别 ★必背

维度高等教育普通教育（基础教育）
专业性质分学科、专业教育传授一般文化科学知识
学校功能更多功能：教育教学、科学研究、社会服务以教学为主
法人地位独立法人地位，直接面向社会，自主办学依附性较强
教育性质非义务教育，学生缴纳学费义务教育为主
属性社会公益性和产业双重性质，事业与产业相结合以公益性为主
高频考点/易混淆点

高等教育与高等教育学的区别：高等教育＝教育活动（实践），高等教育学＝研究规律的科学（理论）。考试常以判断题/名词解释出现。

第一节 小结

  • 高等教育＝有专业方向的教育；三种定义（教科文组织/高教法/自述）
  • 高等教育学＝研究培养高级专门人才规律的科学，二级学科、社会科学
  • 潘懋元《高等教育学讲座》＝独立学科标志（50年代末）
  • 与普通教育五点区别：专业教育、三大功能、独立法人、非义务教育、公益+产业双重性质
第二节

现代高等教育与传统高等教育的区别

定义：

传统教育：一般指大工业生产之前，以德国教育家赫尔巴特为代表的教育思想和教育理论。

现代教育：建立在现代工业社会和现代科学技术基础上的教育，欧美称"新教育""进步教育"。

对传统教育要扬弃而非抛弃——取其精华、去其糟粕。

讲义核心考点：计划经济体制下我国高等教育的四个特点（弊端）

口诀"国条集单"：

  1. 国有化的办学体制
  2. 条块分割的领导体制
  3. 高度集权的管理体制
  4. 单一的培养模式
讲义核心考点：树立市场经济观念的五个转变

口诀"市自立非业"：

  1. 按计划为主 → 按市场需要办学为主
  2. 依赖型 → 自我发展型
  3. 依附型 → 自主型
  4. 义务教育 → 非义务教育
  5. 单一事业型 → 事业、产业型相结合
理解要点

市场经济的特点：自主性、平等性、竞争性、开放性——这决定了高校办学要面向市场、自主办学。

讲义核心考点：建立现代高等教育学的三大动因
  1. 现代科学技术的高度发展
  2. 社会主义市场经济体制的建立和发展
  3. 解决当前高等教育面临的困惑和问题
高频考点/易混淆点

传统教育代表＝赫尔巴特（德国）；现代教育＝"新教育""进步教育"。易误记为杜威——杜威是现代教育（进步教育）代表，赫尔巴特是传统教育代表。

第二节 小结

  • 四弊端：国条集单（国有化/条块分割/高度集权/单一模式）
  • 五转变：市自立非业（面向市场/自我发展/自主/非义务/事业+产业）
  • 三大动因：科技发展 + 市场经济 + 解决困惑
第三节

我国高等教育的基本经验

讲义核心考点：六条基本经验

口诀"党马社教优改"：

  1. 坚持党对教育事业的领导
  2. 坚持马克思主义对学校工作的指导
  3. 坚持教育的社会主义性质和办学方向
  4. 全面贯彻党的教育方针，提高教育质量
  5. 把教育放在优先发展的战略地位
  6. 坚持改革开放方向
讲义核心考点：质量与中心地位

提高质量是高等教育发展的核心任务；牢固树立人才培养在高校工作中的中心地位。

讲义核心考点：两代留学方针
时期留学方针
20世纪80年代按需派遣、保证质量、学用一致
20世纪90年代支持留学、鼓励回国、来去自由
理解要点

数据背景：1949年普通高校在校生仅11.7万余人、研究生仅629人；2008年在校生2907万人，跃居世界第一，实现从精英教育到大众教育的历史性跨越。2009年高校2689所、总规模2979万人、在学研究生140.49万。

第三节 小结

  • 六条经验：党马社教优改
  • 质量是核心任务，人才培养是中心地位
  • 留学方针：80年代"按需派遣保证质量学用一致"；90年代"支持留学鼓励回国来去自由"
第四节

我国高等教育面临的形势和挑战

讲义核心考点：形势＝"三个转变"

口诀"世社转"：

  1. 世纪转换（新世纪、新纪元）
  2. 社会转型（由传统社会向现代社会转型）
  3. 体制转轨（计划经济 → 市场经济转轨）
讲义核心考点：五大挑战

口诀"人科经知文"：

  1. 国际人才大竞争
  2. 高科技大发展
  3. 全球经济大开放
  4. 知识经济大崛起
  5. 多元文化大汇合
理解要点（科技转化加速的例子）

19世纪：发动机发明到应用65年、电话56年；20世纪：雷达15年、尼龙12年、电视11年、激光仅3年——科学技术与经济社会的关系越来越密切，这是"高科技大发展"挑战的典型论据。

科技贡献率：中国30%—40%，发达国家60%以上。

高频考点

中国要与184个国家和地区建立教育合作、与28个国家（地区）签订学历互认协议——常以数字题出现。1978—2007年出国留学121.17万人、回国31.97万人。

第四节 小结

  • 三个转变：世纪转换、社会转型、体制转轨
  • 五大挑战：国际人才、高科技、全球经济、知识经济、多元文化
  • 科技转化周期大幅缩短：发动机65年 → 激光3年
第五节

怎样学习高等教育学

讲义核心考点：学习高等教育学的意义（4点）
  1. 高等教育学是研究探索高等教育规律的科学，学习它能掌握规律
  2. 学习它能反映高等教育的性质、任务，明确办学方向
  3. 学习它能提高干部的专业化水平和管理能力
  4. 学习它能提高教师的教学质量和教育理论素养
讲义核心考点：学习方法（6点）
  1. 以马克思主义为指导
  2. 理论联系实际
  3. 结合现行方针、政策、法规学习
  4. 采用灵活多样的教学方法
  5. 古为今用、洋为中用
  6. 把学习与研究结合起来

第五节 小结

  • 意义：掌握规律、明确方向、提高干部专业化、提高教学质量
  • 方法六条：马指导、联实际、合法规、活方法、古洋用、学研合

导论备考要点速览

一、必背定义与概念

  • 高等教育：对中等教育以上程度的人，传授和研究科学、技术、艺术等学问，培养高级专门人才，是有一定专业方向的教育
  • 高等教育学：以高等教育的特殊矛盾与基本规律为研究对象，研究怎样培养高级专门人才规律的科学（二级学科、社会科学）
  • 传统教育 vs 现代教育：传统＝大工业前以赫尔巴特为代表；现代＝现代工业+科技基础上的"新教育""进步教育"，应扬弃而非抛弃

二、高频考点清单

  • ★ 潘懋元《高等教育学讲座》＝独立学科标志（50年代末）
  • ★ 与普通教育五点区别：专业教育/三大功能/独立法人/非义务教育/公益+产业双重性质
  • ★ 计划经济四弊端：国条集单
  • ★ 五个转变：市自立非业
  • ★ 六条基本经验：党马社教优改
  • ★ 三个转变：世社转；五大挑战：人科经知文
  • ★ 留学方针：80年代按需派遣保证质量学用一致 / 90年代支持留学鼓励回国来去自由

三、易混知识点辨析

  • 高等教育 vs 高等教育学：教育活动（实践） vs 研究规律的科学（理论）
  • 赫尔巴特 vs 杜威：赫尔巴特＝传统教育代表（德国）；杜威＝现代/进步教育代表（美国）
